# 라이프로깅 UX 패턴 레퍼런스

> BeReal, 1 Second Everyday, Snapchat Memories, TikTok "What I eat in a day" 장르에서 추출한 UX 패턴. `/capture`, `/log`, `/reel` 화면 작성 시 참조.

---

## 핵심 통찰: 결과물이 보상이다

라이프로깅 앱이 성공/실패하는 갈림길은 **사용자가 기록 후 받는 보상**의 크기.

- 식사일지 (텍스트) — 보상: 거의 없음 → 실패 (MyFitnessPal도 충분히 성공한 건 다이어트 결과가 보상이라서)
- 1 Second Everyday — 보상: 연말 영상 자동 생성 → 검증
- BeReal — 보상: 친구들의 동시 사진 → 검증
- TikTok 음식 콘텐츠 — 보상: 외부 인정/좋아요 → 검증

today-meal은 **자동 영상 컴파일 = 보상**으로 잡음.

## BeReal 패턴 — 즉흥 캡처 강제

```
[푸시 알림: "Time to BeReal!"]
       ↓
[앱 진입 즉시 카메라 풀스크린]
       ↓
[전·후면 동시 캡처 + 2분 카운트다운]
       ↓
[캡처 완료 → 친구 피드 공개]
```

**적용 가능한 요소**:
- ✅ 시간대 자동 푸시 — "점심 한 컷 찍을 시간"
- ❌ 강제 캡처 — today-meal은 옵트인 원칙 위반
- ✅ 진입 즉시 카메라 — 마찰 최소화
- ❌ 양면 카메라 — 음식 사진에 불필요

today-meal은 BeReal의 **즉흥성 + 푸시 알림** 만 차용. 강제성·시간 압박은 제거.

## 1 Second Everyday 패턴 — 누적 → 자동 컴파일

```
[매일 1초 영상 캡처]
       ↓
[월/년 단위로 자동 합치기]
       ↓
[연말 영상 → 감정적 보상]
       ↓
[구독 모델 — "더 긴 영상" "고급 효과"]
```

**적용 가능한 요소**:
- ✅ 사진 누적 → 자동 영상 컴파일
- ✅ 시간 단위 회고 (하루 / 한 주 / 한 달)
- ✅ 감정적 보상 → 프리미엄 전환 동기
- ✅ 정기적 푸시 ("이번 주 영상이 준비됐어요")

핵심: **자동 컴파일을 사용자가 트리거 안 해도 알아서 만들어준다.** 사용자는 알림 보고 "어? 한 번 보자" → 본 후 "이거 친구들한테 보여주고 싶다" → 공유.

## TikTok "What I eat in a day" 장르

```
[아침 영상 1초]
       ↓
[점심 영상 1초]
       ↓
[저녁 영상 1초]
       ↓
[자동 편집 → 60초 영상 (음악 + 자막)]
       ↓
[#whatIeatInaday 해시태그 + 업로드]
```

**핵심 포맷 요소**:
- 9:16 세로 영상
- 빠른 컷 편집 (각 클립 1~3초)
- 배경 음악 (트렌드 곡)
- 메뉴명 자막 — Pretendard, 굵게, 화면 하단
- 시간/장소 메타 정보 작게

**today-meal에서 자동 재현해야 할 것**:
- 세로 비율 (9:16) 기본, 가로/정사각 옵션
- 사진 + 페이드 트랜지션 (v2.0)
- 사진 위에 메뉴명 텍스트 오버레이
- 음악은 v2.1 (저작권 free 음원 라이브러리)

## 캡처 UX의 마찰 비교

| 진입 깊이 | 예시 | 사용성 |
|---|---|---|
| 0탭 (자동) | 위젯, 워치 단축버튼 | 최고 — v2.2+ |
| 1탭 | 홈에서 [빠르게 기록] | 권장 — v2.0 |
| 2탭 | 메뉴 결정 후 [먹고 사진 찍기] | 자연 — v2.0 |
| 3탭+ | 카테고리 선택 → 메뉴 검색 → 촬영 | 마찰 큼 ❌ |

today-meal `/capture` 진입은 **1~2탭 이내**여야 함.

## 영상 컴파일 UI 흐름

```
[/reel 진입]

  알림: "지난 한 주의 식사 영상이 준비됐어요"
       ↓
  [영상 미리보기 카드]
   - 자동 재생 (음소거)
   - 7장 사진 × 1초씩 = 7초
   - 메뉴명 자막
       ↓
  [Tap]
       ↓
  풀스크린 플레이어 (iOS Photos 스타일)
   - 사운드 on (옵션)
   - [편집] [공유] [다운로드]
       ↓
  [공유] → Web Share API → 인스타/카카오톡 등
```

## 영상 템플릿 종류 (v2.0 → v2.1)

### v2.0: 단일 템플릿 (Minimal)

- 사진 표시 1초씩
- 페이드 트랜지션 (200ms)
- 메뉴명 자막 (Pretendard, 화면 하단, 흰색 + 그림자)
- 우하단 워터마크 `@오늘의밥`
- 음악 없음 (또는 옵션으로 ON/OFF)

### v2.1: 다중 템플릿

| 템플릿 | 분위기 | 특징 |
|---|---|---|
| **Minimal** | 깔끔 | v2.0 그대로 |
| **Vibrant** | 활기 | 빠른 컷, 색감 강조, BGM |
| **Aesthetic** | 감성 | 느린 컷, 필름 필터, 잔잔한 BGM |
| **Story** | 인스타 스토리 | 9:16, 인스타 스토리 톤 |

## 사진 그리드 (`/log`)

iOS Photos 앱의 모먼트 그리드 패턴.

```
─── 2026년 5월 13일 (월) ──────────
┌─────┬─────┬─────┐
│아침 │점심 │저녁 │      ← 시간대별 1행 (또는 자동 행 배치)
│ 🍳  │ 🍜  │ 🍖  │
└─────┴─────┴─────┘

─── 2026년 5월 12일 (일) ──────────
...
```

핵심:
- 정사각 셀 (1:1)
- 셀 사이 갭 2~4px
- 셀 위 작은 시간대 라벨
- 탭 시 풀스크린 단일 사진
- 길게 누르면 액션 시트 (삭제/메뉴 수정)

## 공유 화면

```
┌──────────────────────────────────────┐
│  [Back]    공유할 영상      [Done]   │
├──────────────────────────────────────┤
│                                      │
│        [영상 미리보기 9:16]          │
│                                      │
│  📅 5/7 ~ 5/13                       │
│  🍽️ 21번의 식사                      │
│                                      │
│  [Instagram]  [Threads]  [카카오톡]  │  ← Web Share API
│  [더보기]                            │
│                                      │
│  [다운로드]                          │
└──────────────────────────────────────┘
```

핵심:
- Web Share API (`navigator.share({ files })`) — 시스템 공유 시트
- 다운로드 폴백 (Web Share API 미지원 환경)
- 무료: 우하단 워터마크 (`@오늘의밥`)
- 프리미엄: 워터마크 제거 옵션

## 절대 회피

1. **강제 캡처 / 알림 폭격** — 옵트인 원칙 위반
2. **음식 사진 보정 강요** — 자연스러움이 트렌드의 핵심
3. **소셜 그래프 강제 연동** — BeReal식 친구 강제 추가 ❌
4. **광고를 영상 사이에 삽입** — UX 박살, 공유 동기 ↓
5. **공유하지 않은 사진 외부 송출** — 익명 로컬 원칙. 백엔드 도입 시점에도 옵트인.
